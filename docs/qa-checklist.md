## 1. Аутентификация

### 1.1 Регистрация

- ☐ Открыть приложение, не залогинен → виден экран входа
- ☐ Тап «Регистрация» → форма с email, паролем, ФИО
- ☐ Невалидный email (без @) → ошибка под полем
- ☐ Короткий пароль (< 6 символов) → ошибка
- ☐ Валидные данные → отправляется код подтверждения на email
- ☐ Неправильный код → ошибка, форма не теряется
- ☐ Правильный код → главный экран, новый юзер с пустым профилем

### 1.2 Вход

- ☐ Email + правильный пароль → главный экран
- ☐ Email + неправильный пароль → ошибка
- ☐ Несуществующий email → ошибка без раскрытия что юзера нет
- ☐ После входа закрыть приложение → открыть → сессия восстановлена, без повторного входа

### 1.3 Восстановление пароля

- ☐ «Забыли пароль» → ввод email → сообщение «Письмо отправлено»
- ☐ Письмо приходит за < 1 минуты
- ☐ Переход по ссылке → форма нового пароля → успех → вход

### 1.4 Выход

- ☐ Профиль → «Выйти» → подтверждение → возврат на экран входа
- ☐ После выхода push-уведомления на это устройство больше не приходят

### 1.5 Удаление аккаунта

- ☐ Профиль → «Удалить аккаунт»
- ☐ Двухэтапное подтверждение (ввод слова + чек-бокс)
- ☐ После удаления — экран входа, повторный вход с тем же email невозможен
- ☐ Чужие отзывы об удалённом юзере остаются, но имя автора стирается

## 2. Главная и поиск

### 2.1 Главный экран

- ☐ Гостем — приветствие «Здравствуйте!», без имени
- ☐ Авторизованным — «Здравствуйте, ИМЯ!»
- ☐ Колокольчик в правом верхнем углу — открывает ленту уведомлений
- ☐ На колокольчике бэйдж со счётчиком, если есть непрочитанные уведомления
- ☐ Карточка поиска: «Откуда», «Куда», «Когда»
- ☐ Тап «Откуда» / «Куда» → открывается список городов с поиском
- ☐ Тап «Когда» → календарь (по умолчанию «Сегодня»)
- ☐ Если «Откуда» и «Куда» совпадают — кнопка «Поиск» неактивна
- ☐ Внизу — «История поиска» (до 3 последних маршрутов, тап повторяет поиск)

### 2.2 Результаты поиска

- ☐ Если на маршрут нет поездок — пустое состояние (это нормально)
- ☐ Карточки отсортированы по времени отправления
- ☐ В карточке: маршрут, дата + время, цена, водитель (имя, рейтинг, аватар), число свободных мест
- ☐ Над списком — раздел «Запросы пассажиров» (если есть)
- ☐ Pull-to-refresh обновляет список
- ☐ Тап карточки → детали поездки

## 3. Создание поездки и запроса

### 3.1 Создание поездки (водитель)

- ☐ Таб «Создать» → переключатель «Водитель / Пассажир» → выбран «Водитель»
- ☐ Поля: откуда, куда, дата, время, цена, число мест, авто (предзаполнено из профиля), заметки
- ☐ Переключатель «Мгновенное бронирование» — пассажиры бронируют без подтверждения водителем
- ☐ Переключатель «Макс 2 на заднем»
- ☐ Дата в прошлом → ошибка
- ☐ Время уже прошло сегодня → ошибка
- ☐ Без авто в профиле — поле «Авто» показывает «Не указан», публикация заблокирована
- ☐ Успешная публикация → главный экран, поездка появилась в «Мои поездки»

### 3.2 Создание запроса (пассажир)

- ☐ Переключатель → «Пассажир»
- ☐ Поля: откуда, куда, дата, число пассажиров, комментарий
- ☐ Без авто — публикуется без ограничений
- ☐ После публикации — появляется в каталоге для водителей на этом маршруте

## 4. Детали поездки и бронирование

### 4.1 Просмотр (не своя поездка)

- ☐ Шапка: маршрут + дата + время
- ☐ Карточка водителя — аватар, имя, рейтинг (тап ведёт на его публичный профиль)
- ☐ Авто: модель, цвет, номер, число мест
- ☐ Заметки от водителя (если есть)
- ☐ Список отзывов о водителе (до 3, кнопка «Все отзывы»)
- ☐ Кнопка «Забронировать N мест» (N — из формы поиска)
- ☐ Если своя поездка — кнопок брони нет, вместо них «Редактировать» / «Удалить»

### 4.2 Бронирование

- ☐ Тап «Забронировать» → экран выбора мест
- ☐ Видна схема салона: занятые места затемнены, свободные — выбираемы
- ☐ Выбрать ровно столько мест, сколько в форме поиска
- ☐ Подтвердить → создаётся бронь
- ☐ Без мгновенного бронирования → статус «Ждёт подтверждения»
- ☐ С мгновенным бронированием → статус «Подтверждена» сразу
- ☐ В обоих случаях открывается чат с водителем

### 4.3 Подтверждение / отклонение (водитель)

- ☐ Водитель получает push «Новая заявка»
- ☐ В чате с пассажиром над полем ввода — баннер «Принять / Отклонить»
- ☐ «Принять» → бронь подтверждена, баннер исчезает, в чате появляется системное сообщение
- ☐ «Отклонить» → бронь отклонена, баннер исчезает, пассажир получает push

### 4.4 Отмена брони (пассажир)

- ☐ Мои поездки → бронь со статусом «Ждёт» или «Подтверждена» → «Отменить»
- ☐ Подтверждение → бронь отменяется, места возвращаются в пул

## 5. Мои поездки

- ☐ Таб «Мои поездки» — все будущие и недавние
- ☐ Группировка: «Сегодня», «Завтра», «На этой неделе», «Позже», «Прошедшие»
- ☐ Карточки разных ролей различимы (иконки водителя и пассажира)
- ☐ Тап → детали поездки с управляющими действиями (отмена / удаление / просмотр пассажиров)
- ☐ Прошедшие — помечены «Завершена»

## 6. Чат

### 6.1 Список диалогов

- ☐ Сортировка: новые сверху
- ☐ Превью последнего сообщения + время
- ☐ Непрочитанные — жирный шрифт + индикатор
- ☐ Свайп влево → «В архив»
- ☐ Пустое состояние «Сообщений пока нет»

### 6.2 Архив

- ☐ Профиль → «Архив чатов» → список скрытых
- ☐ Свайп вправо → «Вернуть» возвращает в основной список

### 6.3 Переписка

- ☐ Шапка: аватар + имя партнёра (тап ведёт на его публичный профиль)
- ☐ Свои сообщения справа, чужие слева
- ☐ Время и дата над группами сообщений
- ☐ Системные сообщения по центру (статусы поездки, начало, завершение, напоминание об отзыве)
- ☐ Скролл вниз при новом сообщении
- ☐ Pull-to-load старых сообщений

### 6.4 Отправка

- ☐ Набор текста → кнопка отправки активна
- ☐ После отправки сообщение появляется внизу с галочкой
- ☐ Без сети → красная пометка «Не отправлено», повтор по тапу

### 6.5 Вложения (фото)

- ☐ Кнопка скрепки → выбор фото из галереи
- ☐ Первый раз — запрос разрешения на доступ к галерее
- ☐ Превью загружается в чат, после отправки становится сообщением с фото
- ☐ Тап по фото — полноэкранный просмотр

### 6.6 Напоминание об отзыве

- ☐ После завершённой поездки — в чате с водителем баннер «Оставьте отзыв»
- ☐ Тап → форма с 1–5 звёзд + комментарий
- ☐ Крестик сворачивает баннер (1-й раз — появится снова через 6 часов, 2-й — больше не показывается)
- ☐ После отправки отзыва баннер исчезает навсегда

## 7. Профиль

### 7.1 Свой профиль

- ☐ Аватар (тап → возможность сменить через галерею)
- ☐ ФИО, телефон, email
- ☐ Рейтинг и число поездок
- ☐ Раздел «Авто» (модель, цвет, номер, число мест)
- ☐ Раздел «Настройки»: внешний вид, уведомления, приватность
- ☐ Раздел «Поддержка»: «О приложении», «Условия», «Конфиденциальность», «Связаться»
- ☐ Кнопка «Выйти» внизу

### 7.2 Чужой публичный профиль

- ☐ Шапка: аватар + имя + чипы (рейтинг + число поездок)
- ☐ Карточка «Поездок как водитель / Поездок как пассажир»
- ☐ Раздел «Активные поездки»:
  - Пусто → «Сейчас активных поездок нет.»
  - Есть → карточки с маршрутом, датой, временем, ценой; тап ведёт в детали поездки
- ☐ Раздел «Отзывы»
- ☐ Кнопка «Пожаловаться» в шапке

### 7.3 Жалоба на пользователя

- ☐ Тап «Пожаловаться» → форма
- ☐ Выпадающий список причин + поле комментария
- ☐ Без комментария — ошибка «Опишите проблему»
- ☐ Отправка → успешный alert
- ☐ Жалоба приходит в поддержку на email

### 7.4 Редактирование профиля

- ☐ Изменить ФИО, телефон, страну, пол, дату рождения
- ☐ Сменить аватар через галерею
- ☐ Без сети при сохранении → ошибка, форма не теряется
- ☐ Сохранение → возврат на профиль, изменения видны

### 7.5 Настройки авто

- ☐ Модель / цвет / номер / число мест
- ☐ Пустая модель → нельзя публиковать поездку (см. 3.1)

### 7.6 Внешний вид

- ☐ Светлая / Тёмная / Системная — переключается мгновенно без перезапуска
- ☐ Выбор языка — переключатель есть, но интерфейс остаётся на русском (см. «Известные особенности»)

### 7.7 Уведомления

- ☐ Глобальный переключатель «Push-уведомления»
- ☐ Подпереключатели: новые сообщения, статусы броней, напоминания
- ☐ Настройки сохраняются между сеансами и на других устройствах того же аккаунта

### 7.8 Приватность

- ☐ Переключатель «Показывать профиль другим»
- ☐ При выключении — другие видят только имя и аватар, без рейтинга и поездок
- ☐ **Смена пароля:** ввод текущего пароля + нового + подтверждение
  - Неправильный текущий → ошибка
  - Новый совпадает с текущим → ошибка
  - Меньше 6 символов → ошибка
  - Несовпадение подтверждения → ошибка
  - Успех → сессия сохраняется, новый пароль работает сразу

## 8. Push-уведомления

### 8.1 Регистрация

- ☐ Первый вход после установки → системный запрос «Разрешить уведомления?»
- ☐ «Разрешить» → пуши приходят (см. 8.2 / 8.3)
- ☐ «Не разрешать» → пуши не приходят
- ☐ Изменить разрешение в системных настройках → перезапустить приложение → новый статус применяется

### 8.2 Доставка на iOS

- ☐ Приложение свёрнуто → баннер на Lock screen + в Центре уведомлений
- ☐ Приложение **открыто** → баннер сверху + звук
- ☐ Тап по баннеру → открывается нужный экран (например, если пуш про чат — открывается чат)
- ☐ Бэйдж на иконке приложения обновляется

### 8.3 Доставка на Android

- ☐ Приложение свёрнуто → уведомление в верхней панели
- ☐ Приложение открыто → всплывающий баннер
- ☐ Тап → открывается нужный экран

### 8.4 Реальные триггеры

- ☐ Другой пользователь пишет в чат → пуш приходит получателю
- ☐ Другой пользователь принимает бронь → пуш приходит пассажиру
- ☐ Другой пользователь отклоняет бронь → пуш приходит пассажиру
- ☐ Свой собственный пуш себе НЕ приходит (защита от само-уведомлений)

## 9. Лента уведомлений

- ☐ Колокольчик на главной с бэйджем непрочитанных
- ☐ Открыть ленту — список событий
- ☐ После открытия экрана все помечаются прочитанными (бэйдж пропадает)
- ☐ Pull-to-refresh обновляет

## 10. Smoke-тест (быстрая регрессия)

После любого обновления — пройти эти 7 шагов на чистом устройстве:

1. ☐ Установка свежей сборки
2. ☐ Вход существующим аккаунтом → главный экран
3. ☐ Поиск Душанбе → Худжанд → результаты (или пустой каталог)
4. ☐ Открыть «Мои поездки»
5. ☐ Открыть чат → отправить сообщение
6. ☐ Открыть профиль → выйти → войти заново
7. ☐ Получить тестовый push (при открытом приложении должен показаться баннер)

Если все 7 пунктов зелёные — релиз готов.

## 11. Известные особенности (это не баг)

| Симптом | Объяснение |
|---------|-----------|
| Каталог поездок пустой | В базе нет поездок с будущей датой — нормально, опубликуйте свою через «Создать» |
| Push не приходит на симулятор iOS | Apple Simulator технически не получает push (нужен реальный iPhone) |
| Переключатель языка не меняет интерфейс | Локализация — задача будущая, сейчас всё на русском |
| Своих собственных пушей не получаешь | Так и задумано — приложение не уведомляет автора события |
| Отзыв из старой версии приложения виден в новой | Та же база данных — это правильно |
| Аватары грузятся медленно | Известно, оптимизация запланирована |

## 12. Куда сообщать о багах

- **Воспроизводимый баг:** оформить тикет с шагами, видео или скриншотом, моделью устройства, версией ОС, версией приложения (берётся из «Профиль → О приложении»)
- **Падение (crash):**
  - iOS: «Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики» → найти `HamSafar-*.ips`, приложить
  - Android: bug-report через power-меню или через настройки разработчика
- **Через TestFlight (iOS):** в самом TestFlight есть кнопка «Send Feedback» — отправляет скриншот + текст + версию автоматически
- **Через App Tester (Android):** аналогично, кнопка «Send Feedback» прикладывает контекст
